# MagicalFDSPlug — UI 仕様

## 全体構成

UIは大きく グローバルセクション・キャリアセクション・モジュレータセクション に分かれる。

配置は、グローバルセクションが上部にあり、その下にキャリアセクション・モジュレータセクションの２つが横並びで配置される。キャリアセクションとモジュレータセクションの横幅比は3:2とする。
各セクションには、Magical8bitPlugと同様にセクション名を表すラベルを配置する。マージンの取り方等はMagical8bitPlugに準拠する。

## カラーテーマ

カラーテーマは Magical8bitPlugに準拠し、UIから切り替えとする。

## グローバルセクション

全体に関わる設定を行う。設定項目は以下。

- ボリューム
    プラグイン出力のマスタゲイン。レンジ・デフォルトについてはMagical8bitPlug準拠。
- 同時発音数
    1〜32。デフォルトは 1。
- ベンドレンジ
    対称のセミトーン数を指定。レンジ・デフォルトについてはMagical8bitPlug準拠。
- カラーテーマ
    デフォルトはYMCKカラー。
- フィルタ
    実機に近い出力ローパス（Wiki で言及される ~2kHz 近似）をオンオフするトグルスイッチ。オンにするとローパスフィルタが適用される。デフォルトはオン。カットオフや次数・Qの調整はできない。

## キャリアセクション

キャリアに関する設定を行う。

### エンベロープ

エンベロープは、本来の FDS 音源では 有効／方向／速度 による指定だが、
本プラグインでは実機レジスタとは別モデルとし、
Magical8bitPlugと同じ仕様の ADSR による指定とする。（$408A 相当（音量／変調エンベロープ共通のマスタ速度）は不要）

A, D, S, R の4本のスライダーを提供する。A, D, R の単位は秒。S は相対音量(0〜1)。レンジ・デフォルトについてはMagical8bitPlug準拠。

### キャリア波形

キャリア波形の指定方法として、(1)加算合成 (2)プリセットからの変形 (3)パルス変形 (4)自由描画 の4種類を提供する。波形指定方法はプルダウンにより選択できるようにし、この選択によって対応する専用のUIに置換される。

(1)〜(3)の設定それぞれについては、独立して内部パラメータを保持するようにし、プルダウンで別のものを選択して戻ってきた場合に値が復元されるようにする。例えば、加算合成である程度スライダーを動かした後に、一時的にパルス変形を選んで、もう一度加算合成を選ぶと、先に動かしたスライダーの加算合成の値が復元される。(4)は例外（後述）。

キャリア波形セクションには、大きく２つのパートがある。

- 波形表示パート
    波形を表示する。縦型の細いスライダーとして実装し、キャリアは FDS 実機に準拠した 64 サンプル、モジュレータは累積プレビュー 32 点として表示する。自由描画の場合には実際にスライドして値を変更できるようにする。自由描画以外の場合は読み取り専用とし、プログラムからの更新のみを受け付けるようにする。
    波形表示パートの縦横比は 横：縦＝3:2 とする。
- コントロールパート
    キャリア波形の指定方法に応じたUIを表示する。内容は下述するように方法によって異なる。キャリア波形セクションの表示上の大きさは(1)〜(4)の選択にかからわず固定とする。固定の大きさは一番大きいもの（おそらく加算合成）に合わせ、表示要素が少ない場合は単に空白で埋める。

#### 加算合成

電子オルガンのドローバーの機能を模した スライダーを提供する。
具体的には、オルガンで一般的な9本からサブトーンである 16' を除いた以下の 8本とする。第 9〜16 倍音についてのUIは提供しない。
```
8', 4' ,2⅔', 2', 1⅗', 1⅓', 1 1/7', 1'
```

UI操作によって指定された倍音構成は、いったん理想的な正弦波として合成し、
結果として得られた波形をノーマライズおよび量子化(各サンプル6bit)したものを
音源発音用のパラメータとして採用する。
- ノーマライズの規則は以下とする
    - まず、各スライダーの値を 0〜1 として、その振幅を使って合成を行い、キャリア wavetable の64サンプル位置それぞれについて仮の値を決定する
    - 1を超えるステップがなければ、そのまま量子化に進む
    - 1を超えるステップがある場合、最大のステップが1となるような係数を算出、全ステップにその係数をかける。その後、量子化に進む
- 量子化の丸め規則は、最近傍とする

スライダーはオルガンのドローバーに倣って縦スライダーを横に並べる配置とする。
スライダーの高さは、波形表示パートの高さと同じとする。

#### プリセットからの変形

プリセットとして、以下の波形を用意し、UIのボタンを押すことでこれらを呼び出し、音源発音用のパラメータとして設定する。
- 三角波
- のこぎり波
- サイン波

このプリセットに対して、UIに変形量スライダーを設けて以下の変形を適用できるようにする。スライダーはデフォルトが中央、右に動かすと圧縮、左に動かすと伸長するようにする。
いずれも演算的にはべき乗演算となる。0 のときは 元のプリセット波形そのものとなる。

- 圧縮
    - レベルの絶対値の低いものほどレベルを増幅する。
- 伸長
    - 圧縮の逆。レベルの絶対値の低いものほどさらにレベルを下げる

圧縮／伸長の数式としては、双極 [-1, 1] に正規化された `x` に対して `y = sign(x)|x|^r` とする。
スライダー生値は `t ∈ [-1, 1]`（中央 `t = 0` で無変形）、指数は `r = 5^t`（左端 `r = 0.2`、右端 `r = 5`）。負の `r` は使わない。

UIからこの変形が適用された場合、いったん理想的な値を合成し、
結果として得られた波形を量子化したものを音源発音用のパラメータとして採用する。圧縮／伸長は基本的には-1〜1に正規化された範囲での変形なので、レンジ調整のためのノーマライズは不要。
量子化の丸め規則は、最近傍とする。

#### パルス変形

矩形波に対して、パルス幅を増減させることで波形を変化させる。波形は、Hi/Loレベル(63/0) となる。
UIとしては、パルス幅スライダーを設ける。
スライダーにより、highが連続するパルス幅を 1〜63 ステップの間で調整できるようにする（FDS メイン wavetable は 64 サンプル。デフォルト中央付近は 32）。

#### 自由描画

コントロールパートは表示せず、かわりに波形表示パートの各スライダーを操作可能とすることで、直接波形を指定できるようにする。

この方法だけは例外的にUIの表示値と音源発音用のパラメータとを一対一対応させ、内部値（プリセット選択値＋変形量値など）は持たない。そのため、各スライダーは 6bit(64段階)の離散値とする。

## モジュレータセクション

モジュレータに関する設定を行う。以下の表示要素とコントロールがある。

### 波形表示
モジュレータの波形を表示する。キャリアの波形表示と同様。ただし、こちらは直接スライダーを操作して編集可能とするケースはない。

### コントロール
以下を提供する
- 波形選択
    ボタンとして提供。三角波、ノコギリ波、サイン波、矩形波、上昇、下降、および Custom。プリセットはハードコードされた 3bit 命令列をセットする。Custom 選択時は opcode テキストフィールドが表示される（32 桁の 0..7、空白は無視、全角不可）。有効な入力が確定した時点でのみカスタム opcode 列がパラメータに反映される。
- 変調レート
    変調の周期を決めるパラメータ。実際の周期(Hz)とは単調増加関係ではあるものの、単純な比例にはならない。小さい値ではモジュレーターはLFO的に作用し、大きい値ではFM変調的に作用する。範囲は 0〜4095。
- 変調深さ
    0〜1とし、モジュレータエンベロープの各瞬時出力値と掛け合わせたのち 0〜63 に丸め、FDS 実機の mod gain（NESdev FDS_audio 変調ユニット式）として用いる。
- モジュレータエンベロープ
    こちらもキャリアのエンベロープと同様、本来は 有効／方向／速度 だが、実機レジスタとは別モデルとし、 ADSR でのコントロールを提供する。
