# Magical FDS Plug

## Magical FDS Plugとは

Magical FDS Plug は、いわゆる「ディスクシステム音源」（FDS 音源）の音色を再現するプラグイン形式のソフトシンセです。
Audio Units および VST3 をサポートする Mac / Windows のホストアプリケーション内でご使用いただけます。

FDS 音源は、64 サンプルの波形メモリ（キャリア）を、別の 32 ステップの命令列（モジュレータ）で変調するという独特の仕組みを持ちます。
自由度が非常に高いため設定が難しい音源ですが、本プラグインでは、その自由度を保ちつつ、加算合成やプリセット変形など、ロジカルな方法で波形を組み立てられるインターフェースを提供しています。


## 特徴

- **キャリア＋モジュレータの 2 系統** — 聴こえる基本波形（キャリア）と、それを変える命令列（モジュレータ）を独立に設計できます
- **試行錯誤になりがちな波形設定をロジカルな設定方法でサポート**
  - **加算合成** — 電子オルガンのドローバー風。8 本のスライダーで倍音を混ぜ合わせます
  - **プリセットからの変形** — 三角波・のこぎり波・サイン波をベースに、圧縮／伸長で音色を変えられます
  - **パルス変形** — 矩形波のパルス幅（1〜63）を変えて波形を作ります
  - **自由描画** — 64 点の波形を直接スライダーで描けます
- **モジュレータ 6 プリセット＋ Custom** — 三角波・のこぎり波・サイン波・矩形波・上昇・下降。Custom では 32 ステップの opcode 列（0..7 の 32 桁）をテキスト入力可能
- **変調レートの使い分け** — LFO（ゆっくり揺らす）／FM（音色を変える）／OFF の 3 モード
- **キャリア・モジュレータそれぞれに ADSR エンベロープ** — 音量と変調の時間変化を Magical 8bit Plug 2 と同様の操作感で設定できます
- **実機に近い出力フィルタ** — 約 2 kHz のローパスフィルタをオン／オフできます（デフォルト：オン）
- **プリセットの保存／読込** — 全パラメータを XML ファイルとして保存・読み込みできます

### キャリアとモジュレータ

| パート | 役割 | 特徴 |
| --- | --- | --- |
| **キャリア** | 実際に聴こえる基本の波形 | 64 サンプル・64 段階（6 bit）の波形テーブル。加算合成・プリセット変形・パルス・自由描画の 4 通りで作れます |
| **モジュレータ** | キャリアの読み出し速度（＝音色）を変える命令列 | 32 ステップの 3 bit opcode 列として動作。三角波など 6 種類のプリセットから選び、Custom では opcode を直接指定。レートと深さで LFO 的／FM 的な効果を調整します |

## 主な仕様

| 項目 | 内容 |
| --- | --- |
| 同時発音数 | 1〜32（デフォルト 1） |
| キャリア波形の作り方 | 加算合成／プリセット変形／パルス変形／自由描画 |
| キャリア波形 | 64 サンプル、各 64 段階（6 bit） |
| モジュレータ | 三角波・のこぎり波・サイン波・矩形波・上昇・下降・Custom（32×3bit opcode テキスト） |
| 変調レート | 1〜4095（LFO 時 1〜30、FM 時 30〜4095） |
| 変調深さ | 0〜63（LFO 時 1〜5、FM 時 0〜63） |
| 変調モード | LFO／FM／OFF |
| エンベロープ | キャリア・モジュレータそれぞれ ADSR（Attack / Decay / Sustain / Release） |
| コントロール対応 | ベロシティ（0〜127）／ピッチベンド（±0〜±24 半音） |
| 出力フィルタ | 実機近似のローパス（約 2 kHz）オン／オフ |
| カラーテーマ | 7 種類（FDS / YMCK / YMCK Dark / Japan / Worldwide / Monotone / Mono Dark） |
| プリセット | XML 形式で保存／読込 |
